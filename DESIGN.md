# Elvora Logistics OS interface

Mode: Operate. Preserve all existing record types, routes, permission checks, workflow actions, field labels, document content, and brand assets.

The supplied invoice dashboard is a composition reference, not a source of business data or a replacement brand. The interface uses a light framed workspace, compact dark capsule navigation, generous card spacing, grouped filters, and a dark backing around detailed record workspaces. Elvora's emerald replaces the reference's purple. Do not add fictional metrics, decorative charts, stock imagery, or payment-card credentials.

## Tokens

- Brand: emerald #007b52, deep green #025e3d, signal #c32135, graphite #161d1a.
- Workspace ground #e8ece9; content background #f5f6f5; surface #ffffff.
- Ink #161d1a; body #3f4f47; muted #53655b; rule #e4e9e6.
- Cards 16px radius; outer desktop frame 24px; small controls use capsule radii.
- Typography: existing self-hosted Instrument Sans and Plus Jakarta Sans; Noto Sans Arabic in RTL mode.
- Elevation: 0 12px 36px -24px #193b2b50 on work surfaces.
- Motion: 180–240ms, cubic-bezier(.16,1,.3,1); reduced motion disables tilt and paper feeding.

## Behaviour

The sidebar retains every existing navigation destination. The horizontal module strip provides shortcuts to each permitted group's first destination. Dashboard metrics all remain present; the first four receive visual emphasis. Account cards use bank-account records already available to the signed-in user. PDF printer motion follows real loading states without artificial delays.

At narrow widths the sidebar is a drawer, module navigation scrolls horizontally, metrics use two columns, headers wrap, and tables scroll within their work surface. Dark mode retains its existing support. Print output excludes navigation and animations.
