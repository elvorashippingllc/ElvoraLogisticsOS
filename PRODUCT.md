## Platform

## Stack
Vinext / React on Sites, persistent D1 records and private R2 documents. This is a separate operations application; the existing Elvora website is a reference and stays independently hosted.
## Users
Two internal staff: owner and operations/sales/accounts operator, as explicitly specified in the attached Elvora brief. The initial published audience is the requesting owner's private Sites account. A second operator can be invited through Sites access and assigned an application role.
## Product Purpose
Connect enquiries, quotations, freight jobs, documents, milestones, finance and owner approvals in one shipment workspace.
## Capabilities and Constraints
The supplied briefs define the requested freight OS. Implement durable operational records, server permissions, audit, evidence-led status updates, margins, invoice posting, collection recording, task rules, report exports and private file uploads. No provider credentials were supplied in this turn. Carrier, customs, WhatsApp, email, eInvoice, banking and AI providers must remain visibly unconnected. Sample records are separate from company data and labelled. Warehouse and external portals require operational configuration and are disabled initially.
